# MineWatch — 마인크래프트 속 오버워치

모드 하나만 설치하면 오버워치를 마인크래프트(큐브 블록 스타일 유지)로 즐기는 것을 목표로 하는 프로젝트입니다.
Fabric 1.21.1 / Java 21.

## 현재 상태 (v0.1.0)
**공통 프레임워크**: `Hero` 추상 클래스 + `HeroRegistry` (영웅 추가 = 클래스 하나 + 등록 한 줄), 서버 권위 입력/상태 동기화, 오버워치식 HUD(체력 150 기준, 탄약, 능력, 궁극기), 피해 시스템(OW 체력 150 = 마크 체력 20).

**트레이서**
- 펄스 쌍권총: 히트스캔, 초당 40발, 탄창 40, 재장전 1초, 헤드샷 2배, 15~30m 거리 감쇠(100%→50%), 무적시간 제거
- 블링크: 7블록, 이동 입력 방향(수평), 0.25블록 단위 충돌 검사로 벽 직전 정지, 충전 3개 / 3초당 1개
- 리콜: 20Hz로 위치·시점·체력·탄약 60틱 기록 → 역순 되감기, 무적, 도착 시 최고 체력 복구 + 탄약 충전, 쿨다운 12초
- 펄스 폭탄: 포물선 투척, 블록/적에 부착(적 이동 시 따라감), 폭발 피해 거리 감쇠, 궁극기 자동+피해 충전
- 근접 공격(V)

## 사용법
```
./gradlew build          # build/libs/minewatch-0.1.0.jar
/minewatch hero tracer   # 영웅 선택 (펄스 쌍권총 지급)
/minewatch hero none
```
조작: 좌클릭 사격 · R 재장전 · **Shift 블링크** · **E 리콜** · **Q 궁극기** · V 근접 (키 설정에서 변경 가능)
