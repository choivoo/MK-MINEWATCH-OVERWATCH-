# 서버 운영 (온라인 배틀)

## 설정 파일: `config/minewatch.json`
서버 첫 실행 시 기본값으로 생성된다. 값이 이상하면 안전한 범위로 보정된다.

| 키 | 기본 | 설명 |
|---|---|---|
| minPlayers | 2 | 매치 시작에 필요한 최소 인원 |
| maxPlayers | 12 | 한 매치 최대 인원 (초과분은 다음 매치 대기) |
| queueSeconds | 15 | 최소 인원이 모인 뒤 시작까지 대기 시간(초) |
| fillTeamSize | 0 | 0 보다 크면 각 팀을 이 인원까지 봇으로 채움 |
| botDifficulty | 1 | 0 쉬움 / 1 보통 / 2 어려움 |
| mode | random | tdm / control / random |
| targetKills / targetPoints | 20 / 100 | 데스매치 목표 킬 / 점령전 목표 점수 |

## 동작
- 로비 화면의 "온라인 배틀"로 큐에 참가한다. 인원이 모이면 자동으로 랜덤 맵/모드 매치가 시작된다.
- 매치 중 접속이 끊겨도 팀이 유지된다. 재접속하면 같은 팀·영웅으로 스폰에 복귀한다.
- 매치가 끝난 뒤 돌아온 플레이어는 매치 전 위치(로비)로 이동한다.
- 매치 도중 새로 들어온 플레이어는 로비에 머문다(다음 큐 대기).
- 클라이언트 입력은 서버에서 검증(버튼 비트 마스크, 이동값 [-1,1])하고, 로비 동작은 0.25초당 1회로 제한한다.
- 모든 피해/능력 판정은 서버가 한다(히트스캔 포함).

## 개발: 테스트
- 단위 테스트: `powershell -File scripts\gradle.ps1 test`
- 서버 게임테스트: `powershell -File scripts\gradle.ps1 runGametest`
  (로컬 테스트 서버의 `eula.txt` 에 true 를 기록한다 — 개발자가 직접 허락한 경우에만 사용)
