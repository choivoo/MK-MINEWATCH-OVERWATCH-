# MineWatch 1.0 로드맵

각 마일스톤은 빌드 + runClient 확인 후 커밋한다.

| # | 마일스톤 | 내용 |
|---|---|---|
| M1 | 홈/영웅선택 | 타이틀 화면 "마인워치" 버튼, 홈 화면, 역할별 영웅 선택 화면, 영웅 선택 패킷 |
| M2 | 매치 프레임워크 | 팀(A/B), 매치 상태(대기→카운트다운→진행→종료), 점수/타이머, 스폰, 리스폰, 킬피드 |
| M3 | 공통 체력/궁극기 | 체력+방어구+보호막, 힐팩, 궁극기 충전/준비 알림, HUD 완전 교체 |
| M4 | 오프라인 파티전 | 로컬(통합서버) 다인원 + 분할 없는 LAN 파티, 팀 배정, 모드(팀 데스매치/점령) |
| M5 | AI 대전 | 서버측 봇 엔티티(이동/조준/능력 사용), 난이도 3단계, 봇 vs 플레이어/팀 채우기 |
| M6 | 온라인 대전 | 전용 서버 매치 큐, 로비/준비 상태, 재접속, 지연 보상 점검 |
| M7 | 영웅 확장 | Ability 인터페이스 리팩터링 후 영웅 추가(탱커/딜러/서포터 각 최소 2) |
| M8 | 퍽/사운드/모델 | 퍽 시스템, 합성 대체음 + 리소스팩 구조, 큐브 모델/애니메이션 |
| M9 | 1.0 안정화 | 테스트, 멀티플레이 검증, 문서, 릴리스 jar |

## 설계 메모
- 온라인 대전은 별도 백엔드 없이 "전용 서버 + 서버 내 매치 큐"로 구현한다(외부 매치메이킹 서버는 범위 밖).
- AI는 가짜 플레이어가 아니라 영웅 로직을 공유하는 서버측 봇 엔티티로 구현한다.
